# STM32G431 压力传感器自动测试装置

基于 STM32G431RBT6 的压力传感器测控与自动测试固件。系统输出 4 kHz / 8 kHz PWM 驱动信号，采集压力传感器模拟量，并通过输入捕获校验反馈频率和占空比；LCD 显示实时数据，按键可切换频率、启动六点自动测试和复位测试结果。

> 项目来源说明：这是根据本人蓝桥杯嵌入式备赛工程重新整理的公开复现版。原压力测试应用工程遗失，因此本仓库保留了真实使用过的 STM32G431、ADC、PWM、输入捕获、LCD 和按键技术路线，并重新实现压力换算、双频输出和自动测试流程；不冒充遗失的原始历史版本。

## 功能闭环

1. TIM3_CH2（PA7）输出 4 kHz 或 8 kHz PWM，周期计数为 1000，占空比支持 10.0%–90.0%。
2. ADC2（PB15）读取板载电位器，在手动模式下连续调节 PWM 占空比。
3. ADC1（PB12）采集压力传感器电压，默认按 0.5–4.5 V、0–1.6 MPa 线性传感器换算。
4. TIM2 PWM Input（PA15）同时捕获周期和高电平时间，计算反馈频率与占空比。
5. 自动模式依次执行 `4 kHz/8 kHz × 30%/50%/70%` 六个测试点；每点包含稳定等待、16 次压力采样、反馈容差判断和结果记录。
6. 输入反馈超过 250 ms 未更新即判为丢失；频率误差超过 160 Hz或占空比误差超过 3.0% 时，该测试点失败。

## 系统结构

```text
PB15/R37 ─ADC2─> duty command ─┐
                              ├─> TIM3_CH2 / PA7 ─> drive or loopback
4 kHz / 8 kHz selection ──────┘                         │
                                                       v
PB12/R38 or pressure sensor ─ADC1─> pressure       PA15 / TIM2
                                           ┌──── frequency + duty
                                           v
                                auto-test state machine
                                           │
                                  LCD + LED + key result
```

## 硬件接口

| 功能 | STM32G431 引脚 | 说明 |
|---|---|---|
| PWM 输出 | PA7 / TIM3_CH2 | 4 kHz 或 8 kHz |
| PWM 反馈 | PA15 / TIM2_CH1/CH2 | PWM Input 模式，测周期和高电平 |
| 压力输入 | PB12 / ADC1_IN11 | 板上可用 R38 模拟 |
| 占空比调节 | PB15 / ADC2_IN15 | 板载 R37 |
| 按键 B1–B4 | PB0、PB1、PB2、PA0 | 页面、频率、自动测试、复位 |
| LED1–LED4 | PC8–PC11 | 运行、自动、故障、通过 |

0.5–4.5 V 传感器接入 PB12 前需要分压。参考值为上臂 10 kΩ、下臂 20 kΩ，将 4.5 V 降至 3.0 V；传感器与开发板必须共地。**不得让 STM32 ADC 引脚超过 3.3 V。**

## 操作方法

- B1：切换实时页、自动测试页和接线/标定页。
- B2：手动模式切换 4 kHz / 8 kHz。
- B3：启动自动测试；测试过程中再次按下可中止。
- B4：非测试状态清除统计结果。
- R37：手动模式调节 PWM 占空比。
- R38：没有真实传感器时模拟压力输入。

第一次板测建议用杜邦线短接 PA7 与 PA15。这样可以先验证 PWM 输出、输入捕获和六点自动测试，再接外部驱动和压力传感器。完整步骤见 [板端测试清单](docs/board-test-checklist.md)。

## 工程与代码

- `MDK-ARM/pressure_sensor_tester.uvprojx`：Keil MDK 工程入口。
- `pressure_sensor_tester.ioc`：STM32CubeMX 配置。
- `code/pressure_tester.c`：采集、PWM、输入反馈、LCD、LED和自动测试状态机。
- `code/pressure_math.c`：与硬件解耦的 PWM、压力和捕获计算。
- `code/input_keys.c`：20 ms 非阻塞按键消抖和事件分发。
- `tests/test_pressure_math.c`：可在 PC 上运行的核心算法测试。

## 设计取舍

- 本板 PA7 对应 TIM3_CH2，因此实际使用的是通用定时器，而不是为了简历措辞强行改成不可验证的“高级定时器”。
- 主循环不使用阻塞延时；自动测试由 `HAL_GetTick()` 驱动的状态机执行。
- ADC 读取包含启动、转换完成等待和停止，避免直接读取旧转换值。
- 输入捕获在中断中只保存原始计数，换算和超时判断放在主循环完成。
- 传感器参数、测试容差和时序集中在 `app_config.h`，换传感器时不需要改业务代码。
