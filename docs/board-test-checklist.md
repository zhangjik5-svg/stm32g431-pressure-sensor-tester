# 板端测试清单

## 1. 编译与下载

1. 使用 Keil MDK 打开 `MDK-ARM/pressure_sensor_tester.uvprojx`。
2. 确认已安装 STM32G4 Device Family Pack。
3. 全量重新编译，目标是 0 Error；如出现格式化函数相关警告，确认工程使用的 C 库设置。
4. 通过板载调试器下载并复位。

## 2. 无外设自检

1. 用杜邦线连接 PA7（PWM 输出）和 PA15（反馈输入）。
2. R38 保持中间位置，模拟有效压力电压。
3. 上电后实时页应显示 `FB`，不能长期显示 `NO SIGNAL`。
4. 按 B2 切换频率，反馈值应在 4 kHz 与 8 kHz 附近变化。
5. 旋转 R37，占空比命令和反馈占空比应同步变化。
6. 按 B3 启动自动测试。系统执行六个测试点，约 7 秒后显示结果。

## 3. 示波器检查

- PA7 频率：4.000 kHz / 8.000 kHz。
- 占空比：手动 10%–90%，自动测试点为 30%、50%、70%。
- PA7 高电平：接近 3.3 V；低电平：接近 0 V。
- 切换频率时允许一个更新周期的瞬态，不应持续丢波。

## 4. 压力传感器接入

针对 0.5–4.5 V、0–1.6 MPa 线性传感器：

1. 传感器输出经 10 kΩ / 20 kΩ 电阻分压后接 PB12。
2. 传感器地与开发板 GND 共地。
3. 先用万用表确认 PB12 电压不超过 3.3 V，再连接开发板。
4. 在 0 MPa 和已知标准压力点记录读数，必要时修改 `app_config.h` 中的零点、满量程电压和量程。
5. 比较 LCD 压力值与标准压力源，记录零点误差、满量程误差和重复性。

## 5. 通过标准

- 反馈频率误差不超过 160 Hz。
- 反馈占空比误差不超过 3.0%。
- 250 ms 内持续收到输入捕获更新。
- 传感器重构电压位于 0.40–4.60 V 合理范围。
- 六个自动测试点全部通过后 LED4 点亮。

## 6. 板测完成后应补充的证据

- 开发板、回环线和传感器接线照片。
- 示波器 4 kHz、8 kHz 及 30%/50%/70% 波形截图。
- LCD 实时页和自动测试通过页照片。
- 一张测试数据表：命令频率/占空比、实测值、压力值、误差与结论。
